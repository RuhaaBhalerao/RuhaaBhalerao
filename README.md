## Featured Projects

### MediBridge AI
**AI-Powered Insurance Claim Review Platform**

MediBridge AI is a full-stack healthcare insurance review platform that assists users in navigating complex policy terms and hospital estimates. The platform extracts and processes data from uploaded insurance documents and hospital bills, utilizing strict LLM integration through OpenRouter to deliver contextual claim insights, coverage breakdowns, and out-of-pocket estimates through an interactive interface.

- **Tech Stack:** React, Vite, Node.js, Express, MongoDB, REST APIs, OpenRouter AI, JWT, PDF-Parse, Vercel, Render
- **Key Implementation Areas:**
  - Designed and deployed decoupled frontend and backend services on Vercel and Render.
  - Implemented token-based JWT authentication and user session management.
  - Built document processing pipelines utilizing server-side PDF text extraction for policies and medical estimates.
  - Implemented strict, document-grounded prompt constraints to prevent hallucinations and verify policy conditions against specific billing line items.
  - Developed database-driven chat history and claim record storage for persistent retrieval.

[GitHub Repository](https://github.com/RuhaaBhalerao/MediBridge-AI) | [Live Application](https://medi-bridge-ai.vercel.app/)

### Orderly
**Full-Stack Procurement Management Platform**

Orderly is an enterprise-oriented procurement operations system designed to digitize and manage the purchasing lifecycle from purchase request submission to purchase order generation. Built with Next.js, Express, and PostgreSQL, the platform establishes structured approval hierarchies, supplier evaluations, and auditability for procurement teams without relying on generative AI.

- **Tech Stack:** Next.js, React, TypeScript, Node.js, Express, PostgreSQL, Prisma ORM, Neon, REST APIs, JWT, Zod, Vercel
- **Key Implementation Areas:**
  - Implemented granular Role-Based Access Control (RBAC) with employee ID verification across Requesters, Managers, Procurement Officers, and Admins.
  - Architected requisition workflows enabling multi-tier manager reviews, approvals, and structured rejection feedback.
  - Created a deterministic supplier scoring engine that evaluates suppliers based on weighted parameters including pricing, rating, delivery performance, and risk metrics.
  - Built contract record management, purchase order generation, delivery status tracking, notifications, and immutable audit logs.

[GitHub Repository](https://github.com/RuhaaBhalerao/Orderly) | [Live Application](https://orderlyprocure.vercel.app/)
